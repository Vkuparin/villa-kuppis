# 0.3.0: Two-site Home Assistant and cottage control

Card rules are in [README.md](README.md). Design in [architecture](../architecture.md), [platform decision](../platform-decision.md) and [spot-price automation](../spot-price.md). The owner chose this design on 20 October 2026; it replaces the Android app and Google Home APIs route. Each site gets an always-on mini-PC with its own Home Assistant; Villa Kuppis stays the one UI and planner.

Sequence: H1.1 and the mocked gateway first, without blocking F3.3/F3.5. Then the home transition (H1.2–H1.5) and the cottage's first safe control (H2.1–H2.4), then usability (H2.5, H3.1, F4.3) and hardening (H3.2). The live Windows installation keeps running until H1.5's cutover passes.
